# Almeida Confessor Advocacia

Site institucional do escritório Almeida Confessor Advocacia.

## Estrutura

- `index.html` — página principal
- `assets/images/` — imagens utilizadas pelo site
- `assets/css/` — folhas de estilo
- `assets/js/` — JavaScript
- `previews/` — imagens de referência e capturas
- `scripts/` — scripts auxiliares de desenvolvimento
- `docs/` — documentação do projeto

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Deploy

Projeto preparado para hospedagem em plataformas de sites estáticos, incluindo Vercel.
